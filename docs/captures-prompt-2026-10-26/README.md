# Space Shooter X — captures de référence

Captures du jeu en format mobile portrait (840 × 1520 px), prises le 26 octobre 2026 sur l'ancienne branche `codex/atelier-personnalisation` (fusionnée dans `main`). Elles montrent l'interface AGP-OS et la camionnette dans plusieurs contextes.

| Image | Moment montré |
|---|---|
| `01-carte-missions.png` | Accueil, secteur 1 et ordre de formation |
| `02-atelier-personnalisation.png` | Camionnette dans l'atelier, avec gyrophares, marquage de sécurité et renforts |
| `03-catalogue-rd.png` | Catalogue R&D et cartes d'améliorations permanentes |
| `04-decollage.png` | Cinématique de décollage depuis la Terre |
| `05-combat-formation.png` | Début du combat, HUD et transmission de N.O.R.M.A. |
| `06-combat-mission.png` | Mission en cours, décor et ennemis |
| `07-choix-amelioration.png` | Réquisition d'un atout de mission |
| `08-pause.png` | Menu de pause |
| `09-incident-majeur.png` | Apparition du Dreadnought et jauge de boss |
| `10-rapport-intervention.png` | Rapport de victoire |
| `11-rapport-accident.png` | Rapport de défaite |

Les images proviennent d'une session de test à sauvegarde temporaire. Le boss, les deux rapports et leurs chiffres ont été déclenchés pour la prise de vue ; ils servent de référence visuelle, pas de preuve d'une partie terminée.
